Sim Field Selector

AI Qualifying Demo

Use the installed 58-driver AI roster to run a real local qualifying session and watch the field calculation update live.

Demo roster location

When the installer’s AI roster option is selected, the roster is stored at Documents\iRacing\airosters\Sim Field Selector Demo\roster.json. If iRacing was open during installation, close and reopen the iRacing UI so it discovers the roster.

Run the AI demonstration

  1. Open the iRacing UI and select AI Single Player.
  2. Create a Single Race using a compatible NASCAR Xfinity car and an AI-enabled track you own.
  3. Choose Sim Field Selector Demo as the AI opponent roster and add the desired opponents.
  4. Configure the event with a qualifying session. A 10-minute qualifying session is a useful demonstration length.
  5. Launch Sim Field Selector before qualifying begins. Leave its waiting screen open.
  6. Start qualifying in the simulator. As AI drivers complete laps, qualifying positions and field-transfer calculations will update automatically.
  7. Use Open Live Breakdown for the full four-column qualifying view or Open Broadcast Overlay for OBS.

Important

This is a live AI session, not a replay. The simulator and Sim Field Selector must run on the same computer and at the same Windows privilege level. AI sessions do not affect iRating or Safety Rating.

If the tool remains on “Waiting for the iRacing simulator,” close both programs and restart them normally without using Run as administrator.

This guide remains available from the Testing Instructions button in Sim Field Selector and from Start menu → Sim Field Selector → AI Demo Guide.
